# Agentes IA para Ingeniería de Software - UNTDF

0. Generar clave API como indica "1. Generar proyecto y API Key desde Google AI Studio"
1. Levantar contenedor con `docker compose up -d`
2. Abrir en el navegador el frontend de Flowise `localhost:17860`
3. Importar json de los agentes en un nuevo Flow (drag and drop sobre el canvas)
4. Guardar el Flow (CTRL + S) y probar el chat clickeando en "Playground".
